# rbd-epistasis-landscape

Purpose: Mapping epistatic fitness landscapes of SARS-CoV-2 RBD variants through combinatorial library design, yeast display selection, and sequencing-based enrichment analysis.

This repository contains code analysis workflows used in the dissertation: "Experimental Mapping of the ACE2-Binding Fitness Landscape in the SARS-CoV-2 Receptor-Binding Domain"

Note: Analysis pipelines are currently under refinement. Finalized methods and datasets will be updated alongside publication.
